# MotoMarket · Dissen Studio

Explorador público de patentamientos de motocicletas en Argentina. EN / ES / 中文. Datos agregados CAFAM, 2013–2026, corte al 20/10/2026. No contiene credenciales ni registros individuales.

Frontend estático: HTML, CSS, JavaScript, fuentes locales, SVG y agregados anuales. No instalar dependencias ni ejecutar un build. Publicar con GitHub Pages desde la raíz de la rama main y habilitar HTTPS una vez validado el dominio. Primero verificar propiedad y obtener publicación funcional; luego cambiar únicamente el CNAME motomarket en Porkbun al destino asignado por Pages. Conservar correo y dominio principal. No implementar acceso privado mediante esta publicación estática.
